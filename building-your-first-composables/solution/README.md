# Exercise 01 Solution: Profile Card - Building Your First Composables

## Solution Overview
This is the complete solution for Exercise 01. The ProfileCard composable demonstrates:
- Creating composable functions with proper naming conventions
- Using basic Material Design 3 components (Icon, Text, Button)
- Composing multiple UI elements in a Column layout
- Passing parameters to composables
- Creating preview functions for development

## Key Implementation Details

### ProfileCard Composable
- Uses a `Column` to arrange elements vertically
- Centers content horizontally and vertically
- Includes proper spacing with padding modifiers
- Demonstrates parameter usage for customization

### Components Used
1. **Icon**: Displays a profile picture placeholder using Material Icons
2. **Text (Name)**: Shows the user's name with headline typography
3. **Text (Bio)**: Displays a bio with centered alignment
4. **Button**: Provides a call-to-action for contacting the user

### Best Practices Demonstrated
- Composable functions start with capital letters
- Clear parameter names and types
- Proper use of modifiers for styling
- Preview functions for quick testing
- Comments explain the purpose of each section

## Running the Solution
1. Open this project in Android Studio
2. Sync the Gradle files
3. Run the app on an emulator or device
4. You should see a complete profile card with all elements properly styled

## Learning Points
- Composable functions are the building blocks of Compose UI
- Modifiers allow you to customize appearance and behavior
- Preview functions speed up development
- Material Design 3 provides consistent, beautiful components
