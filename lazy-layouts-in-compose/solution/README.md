# Exercise 08: Lazy Layouts (Solution)

This is the solution code for the Presidents List exercise.

## Features Implemented
- **LazyColumn**: Displays the scrollable list.
- **Sticky Headers**: Groups presidents by **Political Party**.
- **Keys**: Uses unique IDs for list optimization.
- **Card UI**: Displays details (Years in Office, Description) nicely formatted.

## How to Run
1. Open this folder in Android Studio.
2. Build and run the app.
3. Scroll list to observe the Sticky Headers behavior.
